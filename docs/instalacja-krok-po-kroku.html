ZANIM ZACZNIESZ

Co trzeba mieć

✓
Claude Code (zalogowany) i Git for Windows

Claude Code uruchamia skill, Git Bash wykonuje jego skrypty. Logowanie: claude, potem /login.

✓
Dostęp SSH do maszyny

Adres, port, użytkownik i plik klucza prywatnego.

✓
Dostęp do modelu AI

Zalogowany Claude Code na maszynie albo plik z kluczem API Anthropic.

✓
Włączona maszyna

Instancję Azure ML uruchom w Azure ML Studio: wyłącza się sama po bezczynności.

Node.js i OpenClaw nie są potrzebne: skill sam je pobierze na maszynę, do jednego katalogu, i usunie po audycie.

PowerShell · D:\Politechnika\Demo\openclaw-audit

KROK 5 · ZATWIERDZANIE POLECEŃ

Claude pyta o zgodę na każde polecenie

Claude Code

Bash command bash "…/run-audit.sh" --check -c "D:\Politechnika\Demo\moja-maszyna.env" Do you want to proceed? ❯ 1. Yes 2. Yes, and don’t ask again for: bash * 3. No

Przeczytaj polecenie

Widzisz dokładny tekst polecenia, zanim cokolwiek się wykona.

Wybierz 1. Yes, nie 2.

„1” to zgoda na jedno polecenie. „2” zapisze regułę bash *: każdy skrypt bez pytania, na stałe.

Człowiek decyduje

To bramka human-in-the-loop: bez Twojej zgody skill nic nie uruchomi.

KROK 7

Otwórz wygenerowany raport

PowerShell · najnowszy raport

PS> cd D:\Politechnika\Demo PS> $r = ls -Recurse REPORT.html | sort LastWriteTime | select -Last 1 PS> start $r.FullName

Gdzie jest

W katalogu z REPORTS_DIR (domyślnie reports) obok pliku z danymi: <host>_<data-czas>\REPORT.html.

Otwiera się w przeglądarce

Jeden plik, działa offline. Obok leży ta sama treść jako REPORT.md.

Co w środku

Kontrole, analiza agenta, ślad na maszynie oraz surowe dowody w evidence/.
